Source excerpt preview · Hatcher, Chapter 3 · PDF p. 2 / printed p. 186
186Chapter 3   Cohomology

With cohomology, however, the situation is better. One still has a cross product constructed in much the same way as in homology, so one can again take X = Y and get the first half of a product.

Hi(X) × Hj(X) → Hi+j(X × X) → Hi+j(X)

But now by contravariance the second map would be induced by a map X → X × X, and there is an obvious candidate for this map, the diagonal map Δ(x) = (x, x). This turns out to work very nicely, giving a well-behaved product in cohomology, the cup product.

The Idea of Cohomology

Let us look at a few low-dimensional examples to get an idea of how one might be led naturally to consider cohomology groups, and to see what properties of a space they might be measuring.

For a fixed abelian group G, the set of all functions from vertices of X to G also forms an abelian group, which we denote by Δ0(X; G). Similarly the set of all functions assigning an element of G to each edge of X forms an abelian group Δ1(X; G).
