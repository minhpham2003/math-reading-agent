# Tangents v2 — approved interaction specification (2026-11-09)

Status: approved for implementation. **Supersedes the experimental tangent UI in commit 18cb1b83 and subsequent November 9 patches.** Old implementation remains recoverable in Git history; its browser localStorage key `higher-math:tangents:v1:` is untouched and is not treated as a design authority.

## Origins and interaction
- Highlight exact text in a conversation; show contextual **Create Tangent** button. Clicking creates child branch immediately; no confirmation. Original passage remains exactly in place, with only the selected character range linked.
- New tangent shows selected conversation excerpt as read-only context at top of scrollable transcript. No redundant “View in parent” link. Agent waits for user.
- Highlight PDF passage; floating menu offers **Save Citation** and **Create Tangent**. PDF origin creates child of currently active conversation, adds an agent-side linked creation notification **in the parent**, and opens an otherwise empty child transcript. PDF passage is permanently subtly highlighted and links to child. Multiple/overlapping anchors are valid and must not be merged.
- Link hover shows compact title/status preview; when multiple origins overlap, preview and click allow choosing among attached tangents.

## Navigation and settings
- Header: editable current tangent title, ancestor breadcrumb trail, ⚙ settings, **Branches ▾** floating dropdown with collapsible full tree. Middle breadcrumbs collapse into clickable ellipsis based on available width. Tree expansion survives dropdown close, branch switching and session reopen. Active branch highlighted; ✓ green for completed, ● for in-progress.
- Dedicated settings view replaces left conversation area while PDF remains visible. Shows title, parent/origin, available inherited sources and specifically attached passages, with changes explicitly saved. Fine-grained context editing is deferred.
- Header **Return to parent** navigates without finishing or summary. **Finish tangent & return** near composer begins editable summary approval; saving marks completed and returns to immediate parent. Reopening a completed tangent is allowed; status changes to in-progress only upon sending a new message, retaining last approved summary until next finish.
- Navigation preserves parent conversation state and PDF position where possible. Unlimited nested branches.

## Implementation contracts
- Stable branch/message/anchor IDs; one canonical message owner; offsets for exact transcript selection, boxes for PDF highlighting; no rewriting original messages.
- Source inheritance and citation management independent from textual chat transcript. Branch tree data and UI persisted per session, separately from discarded v1 prototype.
- Until AI is connected: notes are user-authored, title is editable heuristic, completion summary is user-authored/editable; never misrepresent autogenerated samples as AI work.
- Test overlapping anchors, message-spanning selection, PDF page jump, refresh persistence, nested branches and empty new tangents.
