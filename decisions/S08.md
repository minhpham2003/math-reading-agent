# S08 — Selecting Too Much Material

**Status:** Design closed — approved by reader  
**Last updated:** 2026-11-08

**Scenario:** The reader selects substantially more material than is realistic for the available session time. The agent should identify the mismatch and help negotiate scope or reading depth without taking control away from the reader.

## Approved design decisions

### S08-D01 — Offer alternative reading strategies

**Status:** Approved — 2026-11-08

**Decision: Option C — Alternative reading strategies**

When the agent believes the selected range is too ambitious for the available time, it should explain the mismatch and offer meaningful alternatives rather than merely warning or automatically shrinking the range.

The alternatives are:
- **Careful reading:** reduce the range to a coherent smaller subset.
- **Overview:** keep the broader range but reduce reading depth.
- **Original plan:** keep the original range and original purpose despite the warning.

The reader chooses which path to take.

**Alternatives considered**
- **A — Warning only:** state that the range is likely too ambitious and leave the next move entirely to the reader.
- **B — Recommend a smaller range:** identify one coherent smaller range as the recommendation.
- **C — Offer alternative reading strategies:** present multiple meaningful strategies, including reduced scope, lighter depth, or keeping the original plan.

**Classification:** Both.
- **Interface obligation:** make the strategy choices explicit and selectable.
- **Agent obligation:** explain the scope mismatch and generate meaningful alternatives without silently changing scope or purpose.

---

### S08-D02 — Respect the original plan immediately

**Status:** Approved — 2026-11-08

**Decision: Option A — Accept immediately**

If the reader chooses to keep the original range and purpose after the agent has warned that it is ambitious, the agent should accept that choice immediately and proceed. It should not repeat the warning, preserve a caution banner, or negotiate again.

**Alternatives considered**
- **A — Accept immediately:** proceed without further resistance.
- **B — Accept, but preserve the warning:** keep the mismatch visible in session state.
- **C — Negotiate once more:** explain likely consequences and ask for a second confirmation.

**Classification:** Agent behavior.

---

### S08-D03 — Hybrid presentation of alternatives

**Status:** Approved — 2026-11-08

**Decision: Option C — Hybrid presentation**

The assessment should briefly explain why the scope looks excessive, then present the available strategies as explicit selectable options.

**Alternatives considered**
- **A — In normal assessment text:** put the alternatives in the Recommendation field conversationally.
- **B — Explicit selectable options:** show the choices as buttons/cards only.
- **C — Hybrid:** brief explanation plus explicit selectable options.

**Classification:** Both.

---

### S08-D04 — Offer several coherent smaller ranges

**Status:** Approved — 2026-11-08

**Decision: Option B — Several coherent ranges**

If the reader chooses **Careful reading**, the agent should offer several mathematically coherent smaller ranges rather than selecting a single range automatically.

**Alternatives considered**
- **A — Choose one recommended range.**
- **B — Offer several coherent smaller ranges.**
- **C — Recommend one range, but make it editable.**

**Classification:** Both.

---

### S08-D05 — Dynamic number of smaller-range options

**Status:** Approved — 2026-11-08

**Decision: Option C — Dynamic number**

The number of smaller-range options should depend on the mathematical structure of the material. A soft default is about 2–3 options, but the agent may show more or fewer when the source naturally supports it.

**Alternatives considered**
- **A — Two options:** one conservative and one more ambitious.
- **B — Three options:** short, medium, and larger realistic ranges.
- **C — Dynamic number:** usually 2–3, but adapt to the source structure.

**Classification:** Agent behavior with UI presentation.

---

### S08-D06 — Informative smaller-range options

**Status:** Approved — 2026-11-08

**Decision: Option B — Informative**

Each smaller-range option should display:
- page range,
- short conceptual title,
- one-sentence description of what the range covers.

**Alternatives considered**
- **A — Minimal:** page range and short title.
- **B — Informative:** page range, conceptual title, and one-sentence description.
- **C — Detailed:** add why the endpoint is natural and a rough time fit.

**Classification:** Both.

---

### S08-D07 — Reassess after choosing a smaller range

**Status:** Approved — 2026-11-08

**Decision: Option B — Brief revised assessment**

After the reader chooses a smaller careful-reading range, the agent should treat that as the actual session scope and run a brief revised S07-style assessment before generating the reading plan.

Flow:
**choose smaller range → revised assessment → reader agrees → proposed reading plan → plan acceptance → begin reading**

**Alternatives considered**
- **A — Immediately treat the choice as the agreed scope.**
- **B — Show a brief revised assessment first.**
- **C — Skip assessment and go directly to the proposed reading plan.**

**Classification:** Both.

---

### S08-D08 — Allow inline adjustment or visual reselection

**Status:** Approved — 2026-11-08

**Decision: Option C — Both adjustment paths**

If none of the suggested smaller ranges is right, the reader can either:
- adjust the start/end range inline, or
- return to the PDF/range selector and choose visually.

The resulting range then follows D07's brief reassessment flow.

**Alternatives considered**
- **A — Choose another range:** return to the PDF/range selector.
- **B — Adjust range inline:** edit start/end pages directly.
- **C — Both:** support inline adjustment and visual reselection.

**Classification:** Interface, with agent reassessment afterward.

---

### S08-D09 — Editable overview strategy

**Status:** Approved — 2026-11-08

**Decision: Option C — Proposed overview strategy**

If the reader chooses **Overview**, keep the full original range. The agent proposes a lighter-depth strategy for the range, including what to prioritize and what can be skimmed or deferred. The reader may edit that emphasis before accepting the plan.

**Alternatives considered**
- **A — Keep the same range, change only reading depth.**
- **B — Keep the same range, but ask what kind of overview is wanted.**
- **C — Propose an overview strategy automatically, but make it editable.**

**Classification:** Both.

---

### S08-D10 — Replace the session purpose with Overview

**Status:** Approved — 2026-11-08

**Decision: Option A — Replace the purpose**

If the reader switches from a purpose such as **Careful first reading** to **Overview**, the session purpose should actually become **Overview** rather than preserving the old purpose as the primary field.

**Alternatives considered**
- **A — Replace the purpose.**
- **B — Preserve both original purpose and adapted strategy.**
- **C — Keep the original purpose unchanged and treat Overview as temporary.**

**Classification:** Both.

---

### S08-D11 — Avoid strong excessive-scope claims when uncertain

**Status:** Approved — 2026-11-08

**Decision: Option A — High-confidence threshold**

If the agent is unsure whether the selected range is genuinely too large, it should avoid labeling it definitively excessive. It may use softer language such as “This range may be ambitious” and still offer the strategy choices.

**Alternatives considered**
- **A — Avoid labeling it excessive unless confidence is high.**
- **B — Ask the reader first about intended proof depth or reading style.**
- **C — Make a best judgment and qualify it.**

**Classification:** Agent behavior.

**Discarded proposal:** An extreme-input edge case such as 150 pages in 45 minutes was explicitly rejected by the reader as unrealistic and is not part of S08's designed behavior.

---

### S08-D12 — Keep the normal S07 plan structure in Overview mode

**Status:** Approved — 2026-11-08

**Decision: Option A — Same conceptual-unit plan structure**

After the reader chooses **Overview**, the agent should still produce the normal S07 conceptual-unit reading plan structure. The units remain title + source location + concise description; they are simply planned at overview depth.

**Alternatives considered**
- **A — Same plan structure:** keep normal conceptual units, framed for overview reading.
- **B — Different overview-plan structure:** organize around focus / skim / optional.
- **C — Hybrid:** keep conceptual units but mark each as Focus, Skim, or Optional.

**Classification:** Both.

## Final user-facing flow

1. Reader creates a session with a selected range, time, and purpose.
2. In the workspace, the agent performs the S07 scope assessment.
3. If the scope is clearly too ambitious, the assessment briefly explains why and offers:
   - **Careful reading**
   - **Overview**
   - **Original plan**
4. If **Original plan** is chosen, proceed immediately with the normal S07 flow.
5. If **Careful reading** is chosen:
   - offer a dynamic set of coherent smaller ranges, usually 2–3;
   - show page range, conceptual title, and one-sentence description;
   - allow either direct range adjustment or visual reselection;
   - reassess the selected smaller range briefly;
   - obtain agreement and continue into the normal S07 proposed-plan flow.
6. If **Overview** is chosen:
   - keep the full range;
   - change the session purpose to **Overview**;
   - propose an editable overview strategy;
   - then use the normal S07 conceptual-unit plan structure at overview depth.
7. If the agent is uncertain whether the scope is excessive, use qualified language rather than a strong judgment.

## Scope boundary

S08 covers negotiation when the selected amount of material is too ambitious for the available session. It does not cover:
- endpoints that cut through an important proof or construction — **S09**;
- detailed purpose/mode design beyond the scope adaptation needed here — **S10**;
- in-reading pacing/checkpoints — **S12/S19**.

## Scenario closure — 2026-11-08

**Goal:** Help the reader recover from an overambitious reading selection without taking control away from them.

**Closed design:** The agent explains the mismatch, offers alternative strategies, respects the reader's choice immediately, and either negotiates a coherent smaller range or adapts the full range to Overview mode. All resulting paths return to the S07 assessment/plan workflow rather than creating a separate planning system.

**Implementation:** Design only. No S08-specific implementation, deployment, browser test, or verified agent behavior has been established in this closure.

**Deferred:** Endpoint integrity → S09; richer session-purpose behavior → S10; in-reading pace changes → S19.
