# S25 — Returning from a tangent

**Status:** Design in progress — approved decisions documented, scenario not closed  
**Updated:** 2026-11-01

**Original scenario:** Reader resolves a prerequisite/proof branch and returns to exactly where the parent reading was interrupted, with enough context to resume.

## Approved design decisions

### S25-D01 — Free navigation from unfinished tangents
**Classification:** Interface (with state preservation). **Status:** Approved — Option A, immediate navigation.  
**Decision:** Branch navigation is immediate and requires no checkpoint or confirmation; an unfinished tangent remains In progress; parent summary does not change. Switching location is distinct from explicit finishing.  
**UI/data:** Preserve full tangent conversation, drafts, scroll, source state and branch state.  
**Agent:** Do not implicitly summarize or mark complete on navigation.  
**Alternatives:** Optional checkpoint; automatic provisional summary. **Evidence:** Reader chose **A**.

### S25-D02 — Restore exact interruption point without extra orientation
**Classification:** Both. **Status:** Approved — Option A, exact restoration.  
**Decision:** After approving finishing summary, return to the original parent position: PDF page/scroll and conversation scroll, plus existing reading context; show updated linked summary in the original extraction location. No unsolicited orientation message. Nested tangents return to immediate parent.  
**Agent:** Do not append a redundant recap message.  
**UI/state:** Preserve and restore return anchor, reading unit and positions.  
**Alternatives:** Short automatic orientation; optional recap control. **Evidence:** Reader chose **A**.

### S25-D03 — Full linked tangent history available to agent
**Classification:** Agent behavior (with retrieval/data support). **Status:** Approved — Option B, full context.  
**Decision:** The parent agent can consult complete linked tangent conversations, including nested tangents, when relevant, not only user-approved summaries. Display summary controls presentation, not available mathematical context.  
**Agent:** Consult detailed discussion as relevant; respect provenance, uncertainties, and corrections; do not confuse full-history access with a requirement to put every transcript in every prompt.  
**Data:** Full transcript and links retrievable.  
**Alternatives:** Summary only; summary-first retrieval. **Evidence:** Reader chose **B** (complete history accessible).

### S25-D04 — Contextual reminders of unresolved questions
**Classification:** Agent behavior. **Status:** Approved — Option B, relevance-sensitive reminder.  
**Decision:** A tangent may be marked Completed even if it contains unresolved questions. When a gap materially becomes relevant later, agent may briefly mention it. Do not repeatedly interrupt, auto-reopen tangent, or initiate a review without reader direction.  
**Agent:** Track outstanding uncertainty and determine relevance conservatively.  
**Alternative:** Preserve silently; require resolution. **Evidence:** Reader chose **B**.
