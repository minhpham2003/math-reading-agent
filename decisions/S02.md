# S02 — Starting a Normal New Reading Session

Status: Prototype complete (reported by reader; not independently verified in this repository)
Last updated: 2026-11-01

## Established design constraints
1. Dashboard-first navigation.
2. A popup for creating sessions.
3. Dark mode.
4. Agent panel on the left, PDF on the right.
5. Nearly full-screen reading workspace.
6. Collapsible reading plan.

These are established constraints for S07 and later design. This record preserves the decisions supplied by the reader; it does not pretend to reconstruct the original S02 discussion, implementation commits, or test evidence.
